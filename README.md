# english-vocab (ארכיון)

האפליקציה עברה למאגר [`apps`](https://github.com/tipul10000-droid/apps), לתיקייה `study/`.
לינק חי: https://tipul10000-droid.github.io/apps/study/

## מה נשאר כאן
- `index.html`: עמוד הפניה (meta refresh + קישור גלוי) מהכתובת הישנה https://tipul10000-droid.github.io/english-vocab/ לכתובת החדשה.
- `supabase/leaderboard.sql`: עותק היסטורי של הגדרת לוח הדירוג. הגרסה הפעילה: `apps/study/supabase/leaderboard.sql`.
- `CLAUDE.md`: כללי העבודה ההיסטוריים (מפתחות localStorage, סדר בלוקים). הגרסה הפעילה: `apps/CLAUDE.md`.
- הגרסה המלאה האחרונה של האפליקציה במאגר הזה נמצאת בהיסטוריה (commit `91e2b3c` ב-main, וענף `podium-icon`).

## הרצה ופריסה
- אתר סטטי. פריסה: GitHub Pages מענף `main`, תיקיית root. כל push ל-`main` מעדכן את האתר.
- הרצה מקומית: `python3 -m http.server` בתיקייה ופתיחת http://localhost:8000
